CURRENT FRONT-DESK GRAPH
=========================

The graph now implements the verified refill branch.
Schedule, billing, records, cancellation, and other non-refill workflows
are still intentionally pending.

The intent_workflow_fanout_node and merge_workflow_results_node shown below
are the scalable design target for the next implementation step. They are
shown here to explain the intended architecture; the current code still uses
the refill path directly.
